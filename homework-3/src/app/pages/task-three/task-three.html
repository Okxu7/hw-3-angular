Angular Built-in Pipes

1. Текстові Pipes

  • uppercase — великі літери: {{ '{{ text | uppercase }}' }}
    Результат: {{ textLow | uppercase }}
  • lowercase — малі літери: {{ '{{ text | lowercase }}' }}
    Результат: {{ textUpper | lowercase }}
  • titlecase — перша літера кожного слова велика: {{ '{{ text | titlecase }}' }}
    Результат: {{ textTitle | titlecase }}

2. Числові Pipes

  • decimal — форматування числа: {{ "{{ number | number:'1.2-2' }}" }}
    Результат: {{ amount | number:'1.2-2' }}
  • percent — відсотки: {{ '{{ number | percent }}' }}
    Результат: {{ progress | percent }}
  • currency — валюта: {{ "{{ price | currency:'USD' }}" }}
    Результат: {{ price | currency:'USD' }}

3. Дата

  • date — форматування дати: {{ "{{ today | date:'dd.MM.yyyy' }}" }}
    Результат: {{ today | date:'dd.MM.yyyy' }}

4. Об'єкти та масиви

  • json — перетворення об'єкта в JSON: {{ '{{ user | json }}' }}
    Результат: 
    {{ user | json }}
  • slice — частина масиву: {{ '{{ fruits | slice:0:2 }}' }}
    Результат: {{ fruits | slice:0:2 }}
  • keyvalue — перебір властивостей об'єкта: {{ '{{ userInfo | keyvalue }}' }}
    Результат: @for (item of userInfo | keyvalue; track item.key) {

    {{ item.key }}: {{ item.value }}

    }

5. Асинхронні дані

  • async — отримання значення Promise: {{ '{{ messagePromise | async }}' }}
    Результат: {{ messagePromise | async }}

6. Локалізація тексту

  • i18nPlural — текст залежно від кількості: {{ '{{ taskCount | i18nPlural:taskMapping }}' }}
    Результат: {{ taskCount | i18nPlural:taskMapping }}
  • i18nSelect — текст залежно від значення: {{ '{{ gender | i18nSelect:genderMapping }}' }}
    Результат: {{ gender | i18nSelect:genderMapping }}
